# Win Capital One

Greptile AE onsite case study: an enterprise account plan for Capital One, presented as a pull request.

Two deliverables, matching the exercise:

- **Account plan** (one page): why now, where Greptile fits, who matters, what I don't know, the outbound sequence, and the first meeting.
- **First call** (five slides): how I'd run the first meeting, show Greptile on their code, prove the value, and win a champion.

Every part has two layers. **Fundamentals** answers the prompt as written. **Fundamentals + plus** shows the additions as a diff: the creative, AI-era moves on top of the basics.

## Use it

- Open `index.html` in a browser, or visit the GitHub Pages site.
- The **Account plan** and **First call** tabs switch between the two deliverables. Link straight to the slides with `#call`.
- **Present the call** steps through the five slides. Arrow keys move, `P` flips the view, `Esc` exits.
- Printing the plan view gives a PDF backup of the one-pager.
- **Objections** opens the answers to the pushback a buyer would give.

## How it was built

Researched and drafted with Claude from public sources (job postings, SEC filings, press, Capital One's open-source repos), then edited by hand. Every change goes through a pull request reviewed by Greptile.
