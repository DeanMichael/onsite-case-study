# Win Capital One

Greptile AE onsite case study: an enterprise account plan for Capital One, presented as a pull request.

Every part of the plan has two layers. **Fundamentals** answers the prompt as written. **Fundamentals + plus** shows the additions as a diff: the creative, AI-era moves on top of the basics.

## Use it

- Open `index.html` in a browser, or visit the GitHub Pages site.
- **Present** steps through the eight parts one at a time. Arrow keys move, `P` flips the view, `Esc` exits.
- **Objections** opens the answers to the pushback a buyer would give.

## How it was built

Researched and drafted with Claude from public sources (job postings, SEC filings, press, Capital One's open-source repos), then edited by hand. Every change goes through a pull request reviewed by Greptile.
